# Database

StudyAI runs on **SQLite** (default, zero setup) or **PostgreSQL** (when `DATABASE_URL` is set). The same code and
the same versioned migrations (`db.py` -> `MIGRATIONS`/`SCHEMA_V1`, `SCHEMA_V2`) are used for both.

| File | Purpose |
|---|---|
| `schema.sql` | PostgreSQL schema, generated: `python manage.py export-schema` |
| `schema.sqlite.sql` | SQLite schema, generated by the same command |

Commands (run from the project root):

```
python manage.py init-db        # create/upgrade tables (also runs automatically when the app starts)
python manage.py seed           # demo account + synthetic data
python manage.py status         # database type, schema version, row counts
```

Seed data is hand-written, synthetic demo content (account `demo@studyai.local`); it is not AI output and the
statistics in it are not real. Tables: users, profiles, documents, chunks, chat_messages, notes, quizzes,
quiz_questions, flashcard_decks, flashcards, study_plans, activity_logs, badges, user_badges, topic_performance,
schema_migrations.
